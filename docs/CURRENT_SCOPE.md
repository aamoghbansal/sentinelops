# Current Build Scope

## What we are demonstrating now

- React dashboard foundation
- FastAPI backend
- Model/project registration
- Scoped Agent credential generation
- SentinelOps local Agent
- AST/file-signature scanning
- scikit-learn detection
- Data-quality checks
- PSI / KS / KL drift detection
- Local-first data flow

## What remains for the next phase

- Retraining policies and training engine
- Model versioning and held-out evaluation gates
- Deployment and rollback
- LLM Copilot / function-calling layer
- XGBoost, PyTorch, TensorFlow/Keras adapters

## Suggested presentation statement

> "For the current development stage, we have completed the foundation and monitoring layer. The current working system can register a model project, pair a local Agent, scan the project, calculate data-quality metrics, and detect statistical drift using PSI, KS-test, and KL divergence. Retraining, model lifecycle management, deployment, and the LLM Copilot are the next development phase."
